
# Release 1.0.2 (2026-10-21)

## CI

- **run the update-deps hook tests via scripts/bin/validate-custom (#19)**
Add scripts/bin/validate-custom, which vrg-validate auto-discovers and runs as its custom stage, so the offline unit tests for scripts/dev/update_deps.py gate every validation run. Fail-defer style modelled on vergil-vm: a missing check script or a missing required tool (uv) is an error, never a silent pass.

## Features

- **publish one runtime package per Python series (#27)**
The runtime is now one package per CPython series, vergil-python<x.y>, installed at /opt/vergil/python/<x.y>. The CPython patch and the PBS build float within the series as in-place upgrades of the same package (epic vergil-project/.github#407, spec section 7; Task 13).

runtime.toml gains series = "3.14". packaging/build.sh installs to the series root and fails unless cpython is a patch of the series and vergil.toml [package] name, version and smoke agree with it. The dependency-update hook bumps cpython only within the series, never rewrites the name or smoke path, and still reports a newer minor as held back.

New tests/test_build.py (run by tests/check-build.sh from validate-custom) covers the series guards and the install root offline, through a fake curl.
