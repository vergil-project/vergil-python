## Features

- **build one package per listed series, refreshed by an upstream-refresh hook (#56)**
runtime.toml becomes a [[series]] list (3.14 and 3.15) and vergil.toml gains one staged [[package]] per series with upstream-version, so vergil-tooling joins the repo VERSION into each package version. packaging/build.sh stages the series named by VRG_PACKAGE_NAME and checks the two files agree one-to-one, the upstream-version, the VRG_PACKAGE_VERSION prefix and the smoke path.

The dependency-update hook becomes the upstream-refresh hook ([upstream-refresh].hook; [dependency-update] is removed). It refreshes each series within itself from the latest PBS release, keeps a series PBS no longer ships at its pin with a 'no longer built upstream' note, never searches older releases, and rewrites both files all-or-nothing.

3.14 was seeded at 3.14.8+20261013 and the hook then brought it to 3.14.9+20261021; 3.15 stays at 3.15.1+20261021.

Ref vergil-project/vergil-python#51

- **add a new leading-edge series once the version window has it (#57)**
The upstream-refresh hook now reads the version window (in_policy python versions of vergil-containers' window.json at the [dependencies].vergil ref, or the local file VRG_VERSION_WINDOW names) and adds each window version newer than the newest listed series that the latest PBS release ships for both architectures, as a new [[series]] entry and [[package]] entry inside the same all-or-nothing write as the refresh. A window version PBS lacks is held back with a note, and newer ones wait for it; it never back-fills or removes a series. This replaces P1's held-back note for a newer PBS minor.
