
# Release 1.0.0 (2026-10-07)

## Bug fixes

- **use secrets: inherit so package-sign receives the environment secrets (#4) (#5)**
Environment secrets reach a job in a cross-repo reusable workflow only with secrets: inherit (probe: vergil-project/packages#6, run 37507168545). With the explicit APP_* map, cd-release's package-sign would get an empty PACKAGE_SIGNING_KEY. Scoped inline nosemgrep plus justification; the callee is first-party.
