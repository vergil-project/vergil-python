## Features

- **add the dependency-update hook for the PBS runtime pin (#12)**
scripts/dev/update-deps.sh (wired as [dependency-update].hook) resolves the newest python-build-standalone release, takes the newest CPython patch of the current minor, and rewrites runtime.toml and vergil.toml [package] together. A newer stable CPython minor is reported to $VRG_DEPS_REPORT, never bumped. Lookup failures, a missing per-arch asset or checksum, and unexpected file layouts fail loud before either file is written. Offline unit tests: tests/check-update-deps.sh.
